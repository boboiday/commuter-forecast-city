One weather forecast for a fictional city that makes a bored commuter smile.

> "Good morning, Umbrella Falls: 14°C, rain falling sideways. Umbrellas are decorative today — the bus is 20 minutes late, and so are you."

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly one line (135 characters) to `/output/entry.txt`. Deterministic: no randomness, no clock, no network.
